# Ruang by Kyral — website project

A responsive, editable vanilla HTML/CSS/JavaScript rebuild based on the available conversation context and uploaded renders. This is a fresh rebuild, not the old original package.

## Open locally

Open `index.html` in a browser. Google Fonts (Playfair Display and DM Sans) load when online; system serif and sans-serif fonts are used as fallbacks. All project imagery is included in `assets/` as lossless WebP files.

## Edit

- `index.html` — page content and project order
- `styles.css` — palette, typography, layout and responsive styling
- `script.js` — mobile navigation and WhatsApp enquiry behavior
- `assets/` — supplied residential, Kopi Malam and Cleanpro renders, losslessly compressed as WebP
